# 这破班还能上多久？｜AI替代与降薪风险体检

给普通职场人使用的免费中文 AI Skill。

它不靠职位名称吓人，也不会假装知道老板哪天裁员。它会逐题了解：

- 你每天真正做什么；
- 哪些任务重复、规则清楚、已经能被AI完成；
- 公司有没有少招人、合岗位、加指标、调薪或PIP等信号；
- 你手里有什么暂时不容易被替代的能力。

## 适合谁

- 担心工作被AI改变的人；
- 感觉公司正在降本增效的人；
- 害怕降薪、裁员，却不知道该看什么信号的人；
- 想转型，但不知道先学什么的人；
- 行政、客服、运营、设计、财务、销售、程序员及其他普通职场人。

## 最简单怎么用

只说一句：

> 我是电商客服，每天主要回复售前问题、处理退款和整理客户反馈，帮我看看这份工作还能干多久。

Skill会每次问一道简单题，信息足够后生成：

1. 工作任务自动化暴露；
2. 公司替代压力；
3. 个人护城河；
4. 有证据的准备窗口；
5. 最可能先被AI改变的三项任务；
6. 30天职场保命行动表；
7. 可截图分享的职场牛马体检卡。

## 它不会做什么

- 不预测具体下岗日期；
- 不猜老板真实意图；
- 不生成降薪或失业概率；
- 不用年龄、性别、婚育、健康或MBTI决定职业风险；
- 不保证用户不会失业、降薪或裁员；
- 不替代劳动法律或人力资源专业意见。

## MBTI有什么用

MBTI只用来调整学习和沟通方式，不参与风险评分。真正决定风险的是实际任务、公司动作和用户能证明的能力。
