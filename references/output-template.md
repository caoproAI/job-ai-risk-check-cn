## 三个动作

### 立即停止

停止把全部时间投入到最容易标准化、最容易交接的低价值任务。

### 应该保留

保留已被证明有效的业务、客户、判断或现场能力。

### 优先补强

只选择一项30天内能留下证据的能力，不列十门课程。

## 30天职场保命打勾表

### 第1周：看清并留证

- [ ] 记录一周任务和时间占比；
- [ ] 保存自己的业绩、流程和作品证据；
- [ ] 核实一个最重要的公司信号。

### 第2周：先让AI替你干活

- [ ] 选择一项重复任务做AI辅助实验；
- [ ] 记录原耗时、新耗时和错误；
- [ ] 建立人工复核清单。

### 第3周：把自己往上挪一层

- [ ] 接手一个需要判断、沟通或业务结果的任务；
- [ ] 做出一个可展示的小案例；
- [ ] 找一位真实同事或客户验证价值。

### 第4周：测试外部退路

- [ ] 查看10个真实同类岗位；
- [ ] 记录最常出现的三项新要求；
- [ ] 更新一段简历或作品；
- [ ] 决定继续、转岗或准备跳槽中的一个下一步。

根据用户每周可用时间缩减，不强迫全部完成。

## 30天后复查

- AI接手的任务占比是否增加；
- 团队人数、招聘和补人是否变化；
- 工作量和绩效口径是否变化；
- 薪资、奖金或补贴是否变化；
- 用户是否留下新的业务结果和作品；
- 外部岗位是否仍需要用户的核心能力。
