# 安装说明

## 本地安装

把整个`job-ai-risk-check-cn`文件夹放进支持标准Agent Skills的工具中。核心文件必须保留名称：

`SKILL.md`

## 从GitHub安装

GitHub仓库创建后，可以使用工具提供的“从GitHub导入”功能。不同工具菜单不同，找不到时下载ZIP再本地上传。

## 能力差异

- 没有联网能力：只能分析用户任务和公司信号，市场信息必须写“未核验”；
- 不能运行脚本：仍可按评分表分析，但必须遵守资料覆盖门槛；
- 不能读取图片：请用户改为文字描述；
- 没有长期记忆：每次复查请用户带回上次的体检卡。

本 Skill 不需要API Key，也不登录公司系统、招聘平台或个人账号。
