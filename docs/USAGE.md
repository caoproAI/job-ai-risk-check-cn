# 使用说明

## 最简单的开始

> 我是郑州制造公司的会计，每天做凭证、对账、报表和报税。帮我看看哪些工作会先被AI改变。

## 检查公司信号

> 最近两个人离职后都没补，公司要求剩下的人用AI多做一倍工作。这算裁员前兆吗？

## 制定改变计划

> 我是运营，每周只能拿出3小时学习。不要给我列十门课，只告诉我未来30天最该补什么。

## 上传材料

可上传已脱敏的：

- 岗位说明；
- 绩效通知；
- 招聘截图；
- 工作流程；
- 调岗或调薪通知。

上传前删除：

- 公司名称；
- 客户和同事姓名；
- 账号、电话和身份证信息；
- 工资明细中的个人身份信息；
- 商业秘密和未公开经营数据。

## 复查

30天后带回“职场牛马体检卡”，并补充：

- 团队人数有没有变化；
- 招聘和补人有没有变化；
- AI接手任务比例有没有增加；
- 指标、奖金和绩效规则有没有变化；
- 自己有没有新的作品、业绩或外部机会。

Skill只更新变化，不重复整套问答。
