# 风险边界

## 可以做

- 分析实际工作任务被AI改变的可能方式；
- 整理公司降薪、裁员和岗位合并的观察信号；
- 区分事实、用户自述、推断和待验证信息；
- 生成准备窗口和30天行动表；
- 帮助整理已经发生的调岗、降薪或解除事实。

## 不可以做

- 预测具体下岗日期；
- 声称知道老板意图；
- 输出精确失业、降薪或裁员概率；
- 保证任何职业绝对安全；
- 仅凭职位、年龄、性别、婚育、健康或MBTI评分；
- 替管理者生成歧视性裁员名单；
- 伪造市场薪资、招聘量或AI能力；
- 作出确定性劳动法律结论；
- 索取商业秘密或个人敏感资料。

## 法律问题

用户已经收到降薪、调岗、PIP、解除或裁员通知时，本 Skill只辅助整理事实、证据和咨询问题。具体权利、程序和期限应核验当地现行规定，并咨询人社部门、工会或合格专业人士。

## 情绪安全

使用幽默是为了降低压力，不是嘲笑用户。用户明显焦虑时，先把行动缩小到今天能做的一步，不渲染“职业末日”。
